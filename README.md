# .github

Organization-level defaults for [DevLyft](https://devlyft.io).

- [`profile/README.md`](profile/README.md) — the public org profile shown at
  [github.com/devlyft](https://github.com/devlyft).

Add shared community-health files here (e.g. `CONTRIBUTING.md`,
`CODE_OF_CONDUCT.md`, `SECURITY.md`, issue/PR templates) to apply them across
every repo in the org that doesn't define its own.
